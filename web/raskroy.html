Вскрываем макет Pixso без MCP

Когда Pixso MCP падает, а по ссылке всё открывается, сам макет уже лежит в вашем браузере. Раскрой берёт его из HAR-файла, разбирает бинарный документ Pixso и собирает описание фрейма для ГигаКода: слои, auto-layout, цвета с токенами, шрифты и все тексты.

Перетащите сюда .har или .zip с ним или нажмите, чтобы выбрать файл · обычно 20–80 МБ Выбрать файл
Файл не покидает браузер: разбор идёт на вашем компьютере, без сервера. В HAR есть токены сессии — не пересылайте его.

Как снять HAR

  1. Откройте фрейм в ChromeСсылка вида …/app/design/…?item-id=185:274028 — этот фрейм откроется первым.
  2. DevTools → NetworkНажмите F12, вкладка Network, включите Preserve log.
  3. Обновите страницуCtrl + R и дождитесь, пока макет полностью отрисуется.
  4. Сохраните HARПравый клик по списку запросов → Save all as HAR with content.

Промпт, который стоит приложить 
Сверстай экран по описанию макета ниже.
- Структуру и отступы бери из flex-row / flex-column, gap и pad.
- Цвета и шрифты бери точно из описания. Если указан [стиль], используй токен дизайн-системы с таким именем, если он есть в проекте.
- «⟶ компонент «…»» — компонент дизайн-системы: если в проекте есть такой компонент, используй его, а не верстай с нуля.
- Координаты @(x,y) нужны только для элементов без auto-layout и с пометкой absolute.
