Раскрой

HAR → макет Pixso → описание для ГигаКода

Вскрываем макет Pixso без MCP

Когда Pixso MCP падает, а по ссылке всё открывается, сам макет уже лежит в вашем браузере. Вставьте ссылку на фрейм, откройте его и нажмите закладку «Раскрой»: она достанет документ из Pixso и соберёт описание для ГигаКода — слои, auto-layout, цвета с токенами, шрифты и все тексты.

Открыть в Pixso
Вставьте ссылку из адресной строки Pixso или из «Копировать ссылку»
Или перетащите сюда пакет .raskroy, .har или .zip пакет сохраняет закладка, HAR — DevTools · нажмите, чтобы выбрать файл
Всё считается на вашем компьютере. Закладка работает от вашего входа в Pixso и только читает файл, ничего не меняя. Данные никуда не отправляются.

По ссылке · один раз настроить

  1. Перетащите кнопку на панель закладок Раскрой ▸ Pixso Панели не видно — Ctrl + Shift + B. Если закладки запрещены, вставьте код в консоль Pixso (F12 → Console).
  2. Откройте макетВставьте ссылку слева и нажмите «Открыть в Pixso», или просто откройте фрейм как обычно.
  3. Нажмите закладку на вкладке PixsoПоявится панель «Раскрой». Через пару секунд нажмите «Копировать для ГигаКода» — описание фрейма окажется в буфере обмена.
Запасной путь: через HAR Откройте фрейм в Chrome → F12 → Network → включите Preserve log → Ctrl + R → дождитесь макета → правый клик по списку → Save all as HAR with content. Перетащите файл слева.

Промпт, который стоит приложить 
Сверстай экран по описанию макета ниже.
- Структуру и отступы бери из flex-row / flex-column, gap и pad.
- Цвета и шрифты бери точно из описания. Если указан [стиль], используй токен дизайн-системы с таким именем, если он есть в проекте.
- «⟶ компонент «…»» — компонент дизайн-системы: если в проекте есть такой компонент, используй его, а не верстай с нуля.
- Координаты @(x,y) нужны только для элементов без auto-layout и с пометкой absolute.
